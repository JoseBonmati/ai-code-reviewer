# Code Review Report for `sample.py`

**Bugs or Security Vulnerabilities**
*   **SQL Injection**: `f"SELECT * FROM users WHERE id = {user_id}"` allows injection attacks (Bandit B608). Use parameterized queries: `cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))`.
*   **Resource Leak**: `sqlite3.connect` is called without closing the connection. Use a context manager (`with sqlite3.connect(...) as conn:`) to ensure proper cleanup and prevent connection exhaustion.

**Performance Optimizations**
*   **Connection Overhead**: Opening a new connection per function call is inefficient. Implement connection pooling or reuse connections for high-throughput scenarios.
*   **Unnecessary Data Fetching**: `SELECT *` retrieves all columns. Specify only required columns to reduce I/O, network, and memory overhead.

**Readability and Cleanliness**
*   **PEP 8 Violations**:
    *   Add two blank lines before function definition (E302).
    *   Remove trailing whitespace on blank lines (W293).
    *   Add newline at end of file (W292).
