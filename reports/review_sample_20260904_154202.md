# Code Review Report for `sample.py`

- **Bugs or Security Vulnerabilities**
    - **SQL Injection (Critical)**: Line 7 uses f-string interpolation for `user_id`, allowing arbitrary SQL execution (Bandit B608). Use parameterized queries (`cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))`).
    - **Resource Leak**: `conn` and `cursor` are never closed, leading to potential connection exhaustion. Use `with` statements or explicit `close()` calls.

- **Performance Optimizations**
    - **Connection Management**: Creating a new SQLite connection per function call is inefficient. Reuse a connection or use a connection pool.
    - **Query Efficiency**: `SELECT *` fetches all columns; specify only required columns to reduce I/O and memory usage.

    - **Whitespace Errors**: Multiple blank lines contain trailing whitespace (W293) and missing newline at EOF (W292) per flake8.
