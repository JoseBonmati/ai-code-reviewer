# Code Review Report for `sample.py`

- **Bugs or Security Vulnerabilities**
  - **SQL Injection (Bandit B608):** F-string query construction allows injection. Replace with parameterized query: `cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))`.
  - **Resource Leak:** Database connection and cursor are never closed, risking connection exhaustion and memory leaks.

- **Performance Optimizations**
  - **Avoid `SELECT *`:** Fetch only required columns to reduce I/O and memory overhead.
  - **Memory Efficiency:** `fetchall()` loads the entire result set into memory. Use `fetchone()` or iterate the cursor since a single `user_id` is expected.
  - **Connection Overhead:** Opening a new connection per call adds latency. Reuse connections or implement connection pooling.

- **Readability and Cleanliness**
  - **Fix Flake8 Violations:** Resolve `E302` (add 2 blank lines before function), `W293` (strip trailing whitespace), and `W292` (add newline at EOF).
  - **Use Context Managers:** Replace manual `connect()`/`cursor()` with `with sqlite3.connect(...) as conn:` for automatic cleanup.
  - **Add Documentation & Types:** Include type hints, docstrings, and explicit handling for empty/missing results.
